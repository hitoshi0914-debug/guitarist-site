世界を揺るがす女性ギタリストたち

世界のハードロック・ヘヴィメタルシーンの第一線で圧倒的なテクニックとカリスマ性を放つ4人の実力派ギタリスト。公式情報源と信頼できる経歴に基づき、彼女たちの軌跡と公式サイト・公式SNSをご紹介します。

    ニタ・ストラウス

    Nita Strauss

    アリス・クーパーの長年のツアーギタリストとして世界を熱狂させ、Ibanez初の女性シグネチャーモデル「JIVA」を持つ世界的ギターヒロイン。ソロ活動でも全米ロックチャート1位を記録。

  • Vixen / The Jetsetters

    ブリット・ライトニング

    Britt Lightning (Brittany Denaro)

    80年代を代表する伝説の女性ハードロックバンド「Vixen」のリードギタリスト。確かな演奏力とダイナミックなステージングで観客を魅了し、ロックキャンプの音楽ディレクターも務める。
